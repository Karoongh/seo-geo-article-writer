# SEO + GEO Article Writer Skill

A complete Grok skill for creating new high-quality articles and deeply correcting previously published articles.

## Features

- **Mode A**: Full new article generation
- **Mode B**: Correction of existing articles (especially high-impression / low-CTR cases)
- Optimized for Search Intent, Semantic SEO, E-E-A-T, Local SEO (when relevant), and GEO (AI answer engines)
- Works for **any topic** (not limited to automotive or Reno Markazi)
- Persian-first natural language support + multilingual capable
- Rank Math package + Schema recommendations
- Multi-role self-review before delivery

## How to use with Grok

Place the skill folder in your Grok skills directory (`~/.grok/skills/seo-geo-article-writer/` or the project skills path). Grok will automatically discover it via the description triggers.

## Structure

```
seo-geo-article-writer/
├── SKILL.md
└── references/
    ├── checklists.md
    ├── rank-math-templates.md
    └── correction-patterns.md
```
