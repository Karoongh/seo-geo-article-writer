# Mode B — Correction Patterns for Published Articles

## Common Failure Modes & Fixes

### 1. High Impressions, Very Low CTR
**Likely causes:**  
- Title or meta does not match the language of the ranking queries  
- Title is generic or lacks a clear benefit  
- SERP snippet does not answer the micro-intent  

**Actions:**  
- Rewrite SEO Title and Meta using the exact phrases from top impression queries  
- Align H1 with the dominant query language  
- Add a stronger value proposition in the first 120 characters of meta  

### 2. Ranking for Many Related Queries but Thin Content
**Actions:**  
- Add dedicated H2/H3 for each high-impression related query  
- Expand the entity coverage  
- Insert short direct answers at the top of each new section  

### 3. Position 5–15 with Stagnant Clicks
**Actions:**  
- Strengthen E-E-A-T signals (sources, clear distinction of certainty)  
- Improve internal linking to and from the page  
- Add practical tables or diagnostic checklists  
- Make the page more extractable for AI Overviews  

### 4. Artificial or AI-Sounding Tone
**Actions:**  
- Rewrite introduction to be problem-first  
- Break long uniform paragraphs  
- Replace formal filler with practitioner language  
- Remove any “we always…” claims that were not supplied by the business  

### 5. Missing Local / Conversion Layer
**Actions:**  
- Add natural CTA after the most valuable section and at the end  
- Include real phone / WhatsApp / address / map only in CTA zones  
- Link to related service pages with natural anchors  

### 6. Safety or Technical Risk
**Actions:**  
- Insert clear warnings where continuing use is dangerous  
- Soften any oversimplified repair instructions  
- Emphasize professional diagnosis when remote certainty is impossible  

## Correction Output Extra Section

When in Mode B, always add inside بخش ۱:

**تشخیص مقاله موجود:**  
- Current ranking queries summary  
- Main CTR / position problems  
- Content gaps vs. high-impression queries  
- Tone and structure issues  
- Recommended priority fixes (title/meta first, then structure, then depth)
