# Deliverable Format

Use this order. Headings stay in Persian when the user works in Persian. Keep sections proportional to the task; skip a section only if it truly does not apply and say so in one line. For Mode B-lite and Mode C, deliver sections 1, 6 and 8 only (plus 2–3 if a rewrite was requested).

## بخش ۱ — تحلیل قبل از نگارش / تشخیص مقاله موجود
Intent (primary and secondary), audience and funnel stage, keyword cluster (Persian variants plus Latin terms), key entities, competitor gaps and the planned information gain, sources used (title + URL). In Mode B add the «تشخیص مقاله موجود» block from `correction-patterns.md`.

## بخش ۲ — ساختار پیشنهادی
H1 plus the H2/H3 tree.

## بخش ۳ — مقاله کامل
Clean WordPress-ready HTML. Deliver as an `.html` file (see SKILL.md) rather than pasting a very long article into the chat. Run the linter first and fix real findings.

## بخش ۴ — CTAهای دقیق
Exact copy and where each goes. Only after value is delivered; match the intent.

## بخش ۵ — FAQ
Question plus a short, independent answer. Only questions that add value. Note that FAQ markup is optional and gives no Google rich result.

## بخش ۶ — بسته Rank Math / SEO
Fields and formulas in `rank-math-templates.md`, plus the schema recommendation from `schema-guide.md`.

## بخش ۷ — تصاویر پیشنهادی
Type, placement, subject, generation prompt if needed, ALT, caption. Mark AI-generated images as such.

## بخش ۸ — کنترل نهایی
- Issues found → fixes applied
- Items intentionally omitted and why
- Linter result (what was flagged, what was accepted and why)
- Residual SEO risks
- **Needs your confirmation:** facts, prices, contact details, author/reviewer name, real experience notes, anything marked `[TO CONFIRM]`
- Sources list (title + URL)
- Ideas for later expansion
- How to measure the result (what to watch in Search Console and for how long)
