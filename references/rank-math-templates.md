## Title Formula Examples (adapt to language & intent)

- [Problem] در [Model/Context] — علت، علائم و راهکار
- معنی [Error Message] روی نمایشگر [Brand/Model]
- تعمیر [Part/System] [Brand/Model] — هزینه، زمان و نکات مهم
- [Service] در [City] — راهنمای کامل + مراجعه

Never force exact keyword if it makes the title unnatural.

## Meta Description Principles

1. Restate the core problem in user language
2. Promise concrete value (causes, diagnosis steps, when to visit)
3. Soft CTA only if it fits (“برای بررسی دقیق‌تر با تعمیرگاه تخصصی تماس بگیرید”)
4. No keyword repetition
5. Matches the dominant Search Intent

## Schema Recommendations

- Most articles → Article + FAQPage (if real FAQ exists)
- How-to / step-by-step → HowTo
- Local service pages → LocalBusiness + Article
- Product comparison → keep Article unless Product schema is truly accurate

Always generate FAQ Schema only from questions and answers that actually appear on the page.
